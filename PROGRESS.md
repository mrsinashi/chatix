## Текущий шаг

M02.11: Админские эндпоинты для управления пользователями (список, редактирование, блокировка, сессии).

## Принятые решения

1. Корень репозитория: `/opt/chatix`.
2. Версии компонентов не назначаются вручную из памяти. Используется скрипт `deploy/collect-latest.sh`, который фиксирует актуальные версии на сервере.
3. После сборки первого каркаса версии будут закреплены в `go.mod`, `package-lock.json`, позже в `Cargo.lock`.
4. PostgreSQL и Valkey на этом этапе используются локально, без внешнего доступа.
5. Каталог `/opt/chatix/bin` будет использоваться для бинарника сервера.

## Отложено

1. Полноценный `Caddyfile` под домен и сертификат организации.
2. Каркас Go-сервера `/healthz` и `/readyz` — следующим шагом после фиксации окружения.
3. Каркас клиента и Tauri — следующим шагом после фиксации окружения.
4. GitHub Actions и публикация Windows-установщика — после привязки к GitHub-репозиторию.

## Открытые вопросы

3. URL GitHub-репозитория для настройки CI.
